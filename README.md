# DrugScreenExplorer

DrugScreenExplorer is a comprehensive R package designed for streamlined processing, quality control, and interactive visualization of high-throughput drug sensitivity screen data. It offers a suite of functions that enable users to efficiently read, assemble, and normalize drug screen datasets. Additionally, the package supports the estimation and correction of edge effect intensity, the summarization of drug responses across concentrations, and a variety of visualization options. To enhance usability, DrugScreenExplorer incorporates an R Shiny application, providing a user-friendly graphical interface that facilitates data analysis, even for those with limited programming experience. DrugScreenExplorer serves as a valuable resource for pharmacologists and biomedical researchers working with large-scale drug screening datasets.


## Install the package

```
if (!require("BiocManager", quietly = TRUE))
    install.packages("BiocManager")

BiocManager::install("DrugScreenExplorer")
```
